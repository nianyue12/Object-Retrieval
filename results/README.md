# Result Layout

This directory is trimmed to the experiments reported in the thesis.

- `main/shapenet/retrieval/`: main ShapeNet retrieval results for Tables 5-2 and 5-4
- `main/shapenet/prompt_tuning/`: reported CoOp and CoCoOp checkpoints
- `ablations/shapenet/retrieval/`: Fusion weight ablation for Table 5-5
- `ablations/os_mn40_core/retrieval/`: OS-MN40-core supplementary experiment for Table 5-8
- `adapter/`: reported post-fusion Adapter checkpoints for hidden dimensions 64, 128, and 256
- `lora/`: reported LoRA checkpoint
- `prompt_tuning/`: reported CoOp and CoCoOp checkpoints

Temporary debug images, legacy Adapter outputs, prompt context-length trials, random-seed trials, and raw duplicate retrieval outputs have been removed.
