# Ablations

This folder stores curated non-main runs that are still useful for comparison and analysis.

Included groups:

- `shapenet/retrieval/`: ShapeNet retrieval ablations such as alternative CoOp settings, seed comparisons, and extra rerank variants
- `shapenet/prompt_tuning/`: prompt-learning ablations including context-length, initialization, and extra test checkpoints
- `shapenet/lora/`: visual LoRA extension experiment outputs
- `os_mn40_core/retrieval/`: OS-MN40-core extension-dataset retrieval runs

These files are copied from the raw result folders so the original outputs remain available.
